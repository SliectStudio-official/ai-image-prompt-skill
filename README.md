# AI 生图提示词模板 —— 科技壁纸

一套专为 **即梦AI（Agent 模式）** 设计的科技感壁纸提示词模板，支持暗色/亮色双模式，助你快速生成高质量企业级操作系统桌面壁纸。

## ✨ 特点

- 🎨 **双模式支持**：暗色模式 & 亮色模式，覆盖不同使用场景
- 🌈 **丰富色系**：冷色、暖色、紫色、绿色等多套色系配套方案
- 📐 **结构化模板**：模式选择 → 风格定调 → 视觉主体 → 点缀细节 → 氛围参数
- 🖼️ **4K 高清**：配合即梦AI「智能超清」功能，轻松输出 2K 画质
- 🔧 **即插即用**：按模板填空即可生成高质量提示词

## 🚀 快速开始

### 1. 打开模板
查看 [科技壁纸提示词模板.md](./科技壁纸提示词模板.md)，了解完整模板结构。

### 2. 组装提示词
按模板的六个步骤组装你的提示词：
1. **确认模式**：暗色 / 亮色
2. **选定色系**：从色表中挑选主色与底色/辅色
3. **视觉主体**：选择几何变体组合
4. **点缀细节**：配置光点颜色
5. **氛围收束**：选择对应气质词
6. 拼接为完整提示词

### 3. 投喂给即梦AI
将组装好的提示词输入到 **即梦AI（Agent 模式）**，选择 **16:9** 比例生成。

### 4. 智能超清
生成后使用即梦AI的 **「智能超清」** 功能提升至 **2K** 画质，下载成品。
