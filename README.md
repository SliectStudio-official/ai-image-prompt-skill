# AI 生图提示词模板 —— 科技壁纸

一套专为 **即梦AI（Agent 模式）** 设计的科技感壁纸提示词模板，支持暗色/亮色双模式，助你快速生成高质量企业级操作系统桌面壁纸。

## ✨ 特点

- 🎨 **双模式支持**：暗色模式 & 亮色模式，覆盖不同使用场景
- 🌈 **丰富色系**：冷色、暖色、紫色、绿色等多套色系配套方案
- 📐 **结构化模板**：模式选择 → 风格定调 → 视觉主体 → 点缀细节 → 氛围参数
- 🖼️ **4K 高清**：配合即梦AI「智能超清」功能，轻松输出 2K 画质
- 🔧 **即插即用**：按模板填空即可生成高质量提示词

## 🚀 快速开始

### 方式一：一键投喂给 AI（推荐）

直接将 [科技壁纸提示词模板.md](./科技壁纸提示词模板.md) **整个文件拖入 AI 对话窗口**（如 ChatGPT、Claude、Trae、Copilot 等），然后告诉 AI：

> 请按照这个模板，帮我生成一个暗色冷色系的科技壁纸提示词。

AI 会自动理解模板结构，替你完成选色、组装、输出最终提示词。示例对话：

```
你：按模板帮我生成一个亮色暖色系的科技壁纸
AI：好的，以下是为您生成的提示词：
    一幅抽象科技背景，无文字，无水印。柔和明亮的渐变，以暖橙与深灰为基调……
```

### 方式二：手动按模板组装

1. 查看 [科技壁纸提示词模板.md](./科技壁纸提示词模板.md)，了解完整模板结构。
2. 按模板的六个步骤组装你的提示词：
   - **确认模式**：暗色 / 亮色
   - **选定色系**：从色表中挑选主色与底色/辅色
   - **视觉主体**：选择几何变体组合
   - **点缀细节**：配置光点颜色
   - **氛围收束**：选择对应气质词
   - 拼接为完整提示词
3. 将组装好的提示词输入到 **即梦AI（Agent 模式）**，选择 **16:9** 比例生成。
4. 生成后使用即梦AI的 **「智能超清」** 功能提升至 **2K** 画质，下载成品。
